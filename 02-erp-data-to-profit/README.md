# ERPAnalyzer

**Одной фразой.** ERPAnalyzer заранее проверяет данные хозяйства из ERP так, как их проверит
банк и государство, и подсказывает, что исправить, чтобы получить льготный кредит и субсидии.

---

## 1. Проблема

У фермера есть учёт в ERP: животные, корма, деньги. Но дешёвых денег он не получает.

- **Кредит.** Банк не может проверить цифры фермера и просит залог на всю сумму. Многие сдаются
  и берут дорогой заём в микрофинансовой организации. В Костанайской области заявки на льготный
  кредит подали 4 хозяйства из 133, от которых их ждали (inbusiness.kz, 06.05.2026).
- **Субсидии.** Государство отказывает из-за мелочей: бычок слишком молодой, нет бирки, нет акта
  взвешивания. Фермер узнаёт об этом уже после отказа.
- **Причина.** Данные в ERP есть, но их никто не проверяет заранее — так, как проверит банк и государство.

## 2. Решение

ERPAnalyzer — дополнительный модуль к ERP. Ничего не нужно вводить заново.

```
1. Берём данные из ERP   →   2. Проверяем                     →   3. Подсказываем
   животные, корма,           как банк: хватит ли денег             фермеру: что сделать
   деньги, заявка             как государство: положена ли            до заявки
   + цены, правила,             субсидия на каждую голову           банку: готовая справка
     камера                   как осмотр: на месте ли скот
```

**Пример.** Фермер собирался продать бычков в октябре. ERPAnalyzer видит: им будет 7 месяцев,
а субсидию дают с 8. Совет — продать в ноябре, и хозяйство получит около 3 млн ₸ субсидии.

## 3. Какие данные приходят

| Данные | Откуда | Что по ним проверяем |
|---|---|---|
| Животные: каждая голова — возраст, вес, бирка, отец | ERP | подходит ли голова под субсидию |
| Корма: сколько съели и сколько на складе | ERP | хватит ли корма в плохой год |
| Доходы и расходы по месяцам, платежи по кредитам | ERP | хватит ли денег на новый кредит |
| Заявка на кредит: сумма, срок, программа | ERP | сколько можно дать |
| Цены на скот, сено, зерно по регионам | статистика stat.gov.kz | сколько стоит стадо, что будет в засуху |
| Правила субсидий | приказ Минсельхоза № 108 | положена ли субсидия |
| Какие коровы на месте | камера, наш CV-трек | есть ли скот, который идёт в залог |

В MVP данные ERP лежат файлами в `data/erp_farms/` (три хозяйства-примера). В жизни — запрос к API ERP.

## 4. Как обрабатываем

**Кредит — как банк.** Берём доходы и расходы за год и считаем, хватит ли денег на все платежи
с запасом. Проверяем падёж, приплод, запас корма и ещё несколько показателей — у каждого есть
норма. Складываем в оценку: надёжное, устойчивое, с рисками или высокий риск. Считаем, сколько
можно дать. И проверяем плохой год на настоящих скачках цен: засуха 2021 года, дорогое зерно,
дешёвый скот.

**Субсидии — как государство.** Каждую голову из реестра проверяем по условиям приказа:
племенной ли отец, кто покупатель, есть ли бирка и акт взвешивания, сколько месяцев будет на дату
продажи, какой вес. Первое невыполненное условие — причина. Одинаковые причины собираем в одно
действие с суммой.

**Залог — как выездной осмотр.** Спрашиваем нашу камеру из CV-трека, каких коров она видела на
месте за сутки, и сверяем с бирками из ERP.

**Итог — список «что сделать».** Все советы собираются в один список, сверху — то, что приносит
больше денег.

### Пример расчёта: хозяйство №1 (так же показано в MVP, блок «Как посчитано»)

| Что считаем | Откуда данные | Расчёт | Результат |
|---|---|---|---|
| Деньги за год | ERP · финансы, 2025-09 — 2026-08 | выручка 59,3 млн − расходы 39,2 млн | остаётся 20,1 млн ₸ |
| Платёж по новому кредиту | ERP · заявка | 37 млн на 84 мес. под 6% | 540 517 ₸ в месяц |
| Все платежи за год | ERP · финансы + заявка | старые 6,0 млн + новый 6,5 млн | 12,5 млн ₸ |
| Хватит ли денег | — | 20,1 ÷ 12,5 (банку нужно не меньше 1,2) | в 1,61 раза — хватит |
| Можно дать по деньгам | — | 20,1 ÷ 1,2 − 6,0 = 10,7 млн в год на новый платёж → кредит на 84 мес. под 6% | 61,2 млн ₸ |
| Сколько стоит стадо | ERP · животные + stat.gov.kz | живой вес КРС 109,9 т × 1 794 ₸/кг | 197,2 млн ₸ |
| Можно дать по залогу | — | половина стоимости стада | 98,6 млн ₸ |
| **Итог** | — | меньшее из двух | **до 61,2 млн ₸** |

Субсидии, то же хозяйство: бычков к продаже 78. Проходят все условия 30 → 2,2 млн ₸. Не проходят:
41 — в октябре им будет 7 месяцев, а нужно от 8 (3,0 млн ₸); 6 — нет акта взвешивания; 1 — нет бирки.
Племенные нетели: 60 × 260 000 ₸ = 15,6 млн ₸. Всего положено 17,8 млн ₸. В MVP можно открыть
проверку каждого бычка.

## 5. Как будет работать в жизни

1. Модуль встраивается в ERP хозяйства и только читает данные.
2. Раз в месяц подтягивает новые цены и пересчитывает всё сам.
3. Фермер видит, что сделать до продажи, покупки или заявки на кредит.
4. При заявке фермер сам отправляет справку в банк.
5. Платит хозяйство (подписка) или банк (за справку). Начинаем с пилота: один банк, двадцать хозяйств.

## 6. Как запустить MVP

Все команды — из папки `02-erp-data-to-profit`. Интернет не нужен.

```bash
.venv/Scripts/erpanalyzer serve
```

Открыть в браузере http://127.0.0.1:8010.

**Живая камера (по желанию).** Во втором окне, из папки `01-computer-vision-cow-id`:

```bash
.venv/Scripts/python -m cowid.cli serve --config configs/mmcows_sensors.yaml --port 8000
```

Без неё ERPAnalyzer берёт сохранённый снимок `data/cv_snapshot.json`.

**Экраны MVP:**

| Экран | Адрес | Что там |
|---|---|---|
| Хозяйство — данные | `/f1` | сами данные: заявка, деньги по месяцам, реестр животных, корма, цены, камера; кнопка «Проверить хозяйство» |
| Хозяйство — результат | `/f1/check` | кредит, субсидии, залог, список «что сделать» и под ними «как посчитано» по шагам |
| Банк — заявки | `/bank` | три заявки с оценкой |
| Банк — справка | `/bank/f1` | итог, почему такая оценка, хватит ли денег в плохой год |
| Данные для банка | `/api/profile/f1` | то же самое в JSON |

Хозяйства переключаются вверху: №1 — маточное стадо, №2 — откормплощадка, №3 — маленькое
хозяйство с КРС и овцами.

**Другие команды:**

```bash
.venv/Scripts/erpanalyzer deck      # пересобрать презентацию (сайт должен быть запущен)
.venv/Scripts/erpanalyzer show      # результаты по хозяйствам текстом
.venv/Scripts/erpanalyzer all       # заново разобрать цены и собрать хозяйства-примеры
.venv/Scripts/python -m pytest -q   # тесты
```

На новом компьютере (нужен интернет для установки):

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/erpanalyzer serve
```

## 7. Честно: что настоящее, а что нет

| Что | Статус |
|---|---|
| MVP: данные → проверка → результат → справка для банка | работает |
| Цены из статистики (71 месяц), правила субсидий, камера CV-трека | настоящие |
| Три хозяйства и их учёт | придуманы для примера (задание это разрешает) |
| Оценка кредита | по нормам и практике кредиторов; на данных банка не проверена |
| Подключение к настоящей ERP, банку, ИСЖ | не сделано — нет доступа |
