# COW ID

Камера в коровнике узнаёт конкретную корову, знает её по реестру фермы,
считает, сколько она лежит и стоит у кормового стола, сравнивает с её
обычными часами и говорит зоотехнику, кого проверить и почему.

> **C14 — лактация 3, стельная 118 дней. Лежит 42% времени, у стада — 19%;
> в реестре хромота 20.06 → возможна хромота, осмотреть ноги.**
> Это не придуманный пример: так система отметила корову на реальной записи
> фермы MmCows (демо «другая ферма», 15:13).

Как запустить к показу и подключить камеру телефона — в корне
проекта: [../README.md](../README.md).

**Запуск:**

```bash
.venv/Scripts/cowid.exe serve
```

Открыть http://127.0.0.1:8000 → «Камера» → «Демо: ферма MmCows — кто это и что
это значит» → «Включить». Через полминуты внизу появится таблица «Узнанные
коровы — что делали и что это значит». Остальные страницы («Сегодня»,
«Стадо», «Корова», «Качество») — на реальных сутках 10 коров MmCows.

**Своя камера:** «Камера» → «Камера телефона или ноутбука» → «Включить».
На ноутбуке работает сразу; для телефона — `cowid serve --phone` и адрес
`https://…:8443`, который напечатает команда (подробно — ../README.md).

**Готовые ролики** (если камеры и видеокарты под рукой нет):
`reports/demo/other_farm.mp4` — главное демо, `cowid_demo.mp4` — всё вместе.
Пересобрать: `cowid demo-video`.

## Команды

Все команды запускаются из этой папки. Короткая форма — `cowid <команда>`;
если `cowid` не находится, то же самое: `.venv/Scripts/python.exe -m cowid.cli <команда>`.
На Windows перед командами с русским выводом: `set PYTHONIOENCODING=utf-8`.

**Данные**

```bash
cowid download frontal_face
```
Скачать датасет (cows2021, frontal_face, mmcows_sensor, mmcows_visual,
mmcows_labels, mmcows_video_0725). Прервать — Ctrl+C, продолжить — та же
команда; `--workers 24`, если сервер медленный.

```bash
cowid verify cows2021
```
Проверить, что архив и каждый распакованный файл целы.

```bash
cowid prepare frontal_face
```
Распаковать и показать, что внутри.

**Модели и проверки**

```bash
cowid train-detector
```
Обучить детектор коров «вид сверху» и сравнить его с готовой моделью
(перепроверка — `cowid eval-detector`).

```bash
cowid train-reid --data <папка, где подпапка = корова>
```
Обучить модель узнавания. Проверка — на коровах, которых модель не видела.

```bash
cowid eval-reid --controls
```
Перепроверить модель узнавания с контрольными проверками и получить порог «не знаю».

```bash
cowid mmcows-detector
```
Детектор коров на другой ферме: до дообучения, дообучение, «лежит/стоит».

```bash
cowid farm-chain
```
Вся цепочка на другой ферме с ответами: дообучение узнавания 16 коров,
IDF1 и подмены номера, часы лёжа и у корма против разметки людей
(`reports/mmcows/chain.json`).

**Ферма**

```bash
cowid init-camera configs/camera.yaml
```
Создать настройки своей камеры (зоны, калибровка, пороги).

```bash
cowid enroll --data <папка с фото> --config configs/cows2021.yaml
```
Зарегистрировать коров по фото (имя подпапки = номер).

```bash
cowid process запись.mp4 --day 2026-09-16 --config configs/camera.yaml
```
Обработать запись камеры за сутки.

```bash
cowid check-video
```
Прогнать конвейер на реальных роликах Cows2021.

```bash
cowid import-mmcows
```
Загрузить реальные сутки 10 коров MmCows в базу и проверить детектор отклонений.

```bash
cowid serve
```
Платформа: http://127.0.0.1:8000 (по умолчанию — `configs/mmcows_sensors.yaml`).

```bash
cowid serve --phone
```
То же, плюс адрес для телефона в той же сети и https на порту 8443 — без https
браузер телефона не даёт камеру. Сертификат создаётся сам (`var/tls/`, нужен
openssl — он есть в Git for Windows).

**Расчёты**

```bash
cowid scenarios
```
Что детектор отклонений замечает, а что нет (заданные сценарии).

```bash
cowid economics --herd 500
```
Экономический эффект на стадо.

**Проверка кода**

```bash
.venv/Scripts/python.exe -m pytest -q
```

## Установка с нуля

Проще всего — `start.ps1` в корне проекта: ставит всё сам и скачивает модели
(подробно — [../README.md](../README.md)). Вручную: сначала torch под свою видеокарту — команды в начале `requirements.txt`. Затем:

```bash
python -m venv .venv
```

```bash
.venv/Scripts/pip install -r requirements.txt
```

```bash
.venv/Scripts/pip install --no-deps -e .
```

Развёртывание на площадке — `deploy/`.
