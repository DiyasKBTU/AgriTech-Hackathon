# AgriTech Hackathon 2026 — два трека, одна ферма

| Папка | Трек | Что это |
|---|---|---|
| `01-computer-vision-cow-id/` | Computer Vision | **COW ID** — камера узнаёт каждую корову, знает её по реестру фермы, считает, сколько она лежит, ест и пьёт, и говорит зоотехнику, кого осмотреть |
| `02-erp-data-to-profit/` | ERP | **ERPAnalyzer** — заранее проверяет данные хозяйства из ERP, как их проверят банк и государство, и подсказывает, что исправить, чтобы получить льготный кредит и субсидии |

Треки связаны: ERPAnalyzer спрашивает у COW ID, какие коровы на месте, — так банк видит,
что скот в залоге существует.

## 1. Запуск перед показом (5 минут, интернет не нужен)

Нужны два окна терминала — по одному на трек.

**Окно 1 — COW ID** (папка `01-computer-vision-cow-id`):

```bash
cd "D:/Projects/AgriTech Hackathon/01-computer-vision-cow-id"
```

```bash
.venv/Scripts/cowid.exe serve --phone
```

Откроется платформа http://127.0.0.1:8000. Флаг `--phone` нужен, только если будете
показывать камеру телефона: команда напечатает адрес для телефона вида
`https://192.168.x.x:8443/#/live`. Без флага — просто `.venv/Scripts/cowid.exe serve`.

**Окно 2 — ERPAnalyzer** (папка `02-erp-data-to-profit`):

```bash
cd "D:/Projects/AgriTech Hackathon/02-erp-data-to-profit"
```

```bash
.venv/Scripts/erpanalyzer.exe serve
```

Откроется MVP http://127.0.0.1:8010. Если COW ID запущен, проверка залога берёт данные
у него; если нет — из сохранённого снимка.

Остановить любой сервер — `Ctrl+C` в его окне.

## 2. Как работать с COW ID (http://127.0.0.1:8000)

| Вкладка | Что показать | Что нажать |
|---|---|---|
| **Камера** | главное демо: номера коров C01–C16 на записи фермы, карточка из реестра, часы лёжа и у корма против её обычных часов, вывод «возможна хромота — осмотреть ноги» | «Демо: ферма MmCows — кто это и что это значит» → «Включить». Через 20–30 секунд внизу появится таблица «Узнанные коровы»; нажать на корову — карточка |
| **Сегодня** | утренний экран зоотехника: кого осмотреть и почему, три вопроса уверенности, «подтверждаю / ложная тревога» | ◀ ▶ — выбрать сутки; 31.07 — пример «Всё стадо» |
| **Стадо** | все коровы за сутки: значение, её норма, насколько отличается | нажать на корову — её страница с графиками |
| **Качество** | чем и как проверены модели | — |

Реальные данные: записи и датчики фермы MmCows (США) и Cows2021 (Великобритания).
Выводы — признаки, а не диагнозы; хромота — косвенный признак по поведению.

### Подключить камеру

Вкладка **«Камера»**, пункт **«Камера телефона или ноутбука»**.

**Камера ноутбука:** выбрать пункт → «Включить» → браузер спросит доступ к камере →
«Разрешить». Кадр с рамками появится через пару секунд, в углу — маленькое окно самой камеры.

**Камера телефона:**
1. На ноутбуке сервер запущен с `--phone` (см. раздел 1).
2. Телефон в той же сети, что и ноутбук: один Wi-Fi или ноутбук подключён к точке доступа
   телефона (в залах Wi-Fi часто не пускает устройства друг к другу — тогда точка доступа).
3. На телефоне открыть адрес, который напечатала команда (он же есть на странице «Камера»
   у пункта «Камера телефона или ноутбука»), например `https://192.168.2.100:8443/#/live`.
4. Браузер предупредит о сертификате — «Дополнительно» → «Перейти на сайт». Так и должно
   быть: сертификат свой, для домашней сети.
5. «Камера телефона или ноутбука» → «Включить» → разрешить камеру. Кадр с рамками
   видно и на телефоне, и на ноутбуке (проектор).

Windows при первом запуске с `--phone` может спросить про брандмауэр — разрешить для
частной сети.

**«Как стоит камера»:** *сбоку или под углом* — готовая модель находит коров на любом кадре
(например, фото коровы на экране), номера не ставятся; *сверху над проходом* — наш детектор
и узнавание коров, как на ферме. Коров в зале нет — система всё равно показывает, что камера
работает: кадры в секунду, яркость, резкость; закройте объектив рукой — «темно».

Другие источники там же: камера компьютера по номеру (USB), IP-камера или приложение IP Webcam
по ссылке.

**Если не работает:**

| Что видно | Что сделать |
|---|---|
| «камера не найдена» | у компьютера нет камеры или она выключена в настройках Windows |
| «камера занята другой программой» | закрыть Zoom, Teams, «Камеру» Windows |
| «доступ к камере запрещён» | значок замка в адресной строке → Камера → Разрешить |
| телефон не открывает адрес | телефон и ноутбук в разных сетях — включить точку доступа на телефоне и подключить к ней ноутбук, перезапустить `cowid serve --phone` |
| на телефоне «страница открыта по http» | открыть именно `https://…:8443`, а не `http://…:8000` |

Запасной вариант без камеры и видеокарты — готовые ролики
`01-computer-vision-cow-id/reports/demo/other_farm.mp4` (главное демо) и `cowid_demo.mp4` (всё).

## 3. Как работать с ERPAnalyzer (http://127.0.0.1:8010)

1. **Хозяйство — данные** (`/f1`): что пришло из ERP и снаружи → кнопка «Проверить хозяйство».
2. **Результат** (`/f1/check`): сколько кредита потянет, сколько субсидий положено, на месте ли
   скот, и список «что сделать», самое денежное — первым.
3. **«Отправить справку в банк»** → экран банка (`/bank/f1`): сколько можно дать, почему, хватит
   ли денег на платежи в засуху.

Хозяйства переключаются вверху (№1 маточное стадо, №2 откормплощадка, №3 КРС и овцы) —
это примеры; цены stat.gov.kz и правила субсидий — настоящие. Подробнее —
[02-erp-data-to-profit/README.md](02-erp-data-to-profit/README.md).

## 4. Установка на новом компьютере

Нужен Python 3.13 и интернет (только для установки). Для каждого трека — своё окружение.

**COW ID** (папка `01-computer-vision-cow-id`): сначала torch под свою видеокарту
(команды — в начале `requirements.txt`), затем:

```bash
python -m venv .venv
```

```bash
.venv/Scripts/pip install -r requirements.txt
```

```bash
.venv/Scripts/pip install --no-deps -e .
```

Модели и данные в репозиторий не входят (сотни мегабайт): папки `models/`, `data/`, `var/`,
`reports/` переносятся копированием. Без видеокарты всё работает, но медленнее.

**ERPAnalyzer** (папка `02-erp-data-to-profit`):

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python -m pip install -e ".[dev]"
```
